Conector Booking do HospedaMais

A extensão lê somente a reserva aberta em admin.booking.com, mostra uma prévia e envia para conferência no HospedaMais. Ela não salva a senha da Booking.

1. Baixe o projeto
Baixar extensão
Extraia o ZIP e localize a pasta booking-chrome-extension.
2. Abra o gerenciador do Chromechrome://extensionsAtive “Modo do desenvolvedor” no canto superior direito.
3. Instale
Carregar sem compactação → selecionar booking-chrome-extension
4. Configure no ícone HospedaMais
Endpoint: https://xjdqjjfnpcnywrkxentv.supabase.co/functions/v1/booking-browser-ingestO ID da empresa e o token aparecem na tela Integrações do HospedaMais após a ativação.
5. Teste
Abra uma reserva na Extranet, clique no ícone HospedaMais, confira os dados e pressione “Enviar para conferência”.
